# slotnet

Slot digests and net fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/slotnet/

## Install / run

```bash
git clone https://github.com/theworker02/slotnet.git
cd slotnet
node src/cli.js
node --test
```
